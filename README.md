# Hybrid Steel–Concrete Floating Wind Turbine Foundations
This repository contains multi-software parametric scripts and numerical model files supporting the paper:
> A Parametric Multi-Software Integrated Method for Strength Assessment of Hybrid Steel–Concrete Floating Wind Turbine Foundations, Ships and Offshore Structures

## Content
- Scripts: Multi-software integration code for strength assessment
- Numerical models: Hybrid steel-concrete floating foundation models
